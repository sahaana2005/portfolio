# Sahaana Raajkumar — Creative Developer Portfolio

An interactive, immersive 3D personal portfolio featuring smooth mouse-tracked 3D character animation, custom loaders, responsive layout, and modern aesthetics.

## ✨ Features

- **Interactive 3D Character Hero**: Real-time cursor and touch tracking with 360-degree multi-frame character rendering and spring physics.
- **Custom Liquid Glass / Gooey Preloader**: Elegant branded entrance animation.
- **Modern Tech Stack**: Built with Vite, React 19, TypeScript, and Tailwind CSS.
- **Responsive & High Performance**: Optimized canvas frame rendering and smooth transitions across desktop and mobile screens.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sahaana2005/PORTFOLIO.git

# Navigate into the project directory
cd PORTFOLIO

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Building for Production

```bash
npm run build
```

The production-ready assets will be generated in the `dist/` directory.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **3D / Canvas**: Custom canvas frame interpolation & Spline Runtime
- **Language**: [TypeScript](https://www.typescriptlang.org/)
